This repository accompanies a thesis on credibility heuristics in user 
comments on TikTok historical content. It contains the full code, the 
raw and processed datasets, and the figures reported in the thesis.

## About the project

This thesis investigates how credibility heuristics — the cognitive 
shortcuts users rely on when judging whether information is trustworthy — operate in an algorithmically curated short-video environment. Drawing on Sundar's MAIN model (2008) and Metzger and Flanagin's heuristic typology (2013), it develops a topic-adapted framework of eight heuristic categories organized across three dimensions: platform-situated, content-related, and user-related cues.

The project adopts a Computational Grounded Theory approach (Nelson, 2020), combining semi-supervised classification (SetFit) with interpretive close reading. The classification pipeline was applied to nearly 6,000 comments, and the final classification was applied to 2,310 comments collected from TikTok history videos; close reading was then conducted on samples drawn from each category to identify the specific signals users invoke in their credibility judgments.

The thesis addresses two research questions:

- **RQ1**: In what way are these platform-situated heuristic cues 
  empirically observable in user comments on TikTok history videos?
- **RQ2**: How do these heuristic cues differ from those identified in 
  pre-algorithmic credibility frameworks?
